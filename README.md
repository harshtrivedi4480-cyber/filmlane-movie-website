# 🎬 Filmlane — Movie Website

Filmlane is a responsive movie discovery website where users can browse trending movies, top-rated films, upcoming releases, and TV series — with a clean login/signup UI.

## 🚀 Live Demo
Deployed on Vercel: _add your live link here after deploying_

## ✨ Features
- Responsive landing page with hero, trending, top-rated, upcoming, and TV series sections
- Movie details page with full info layout
- Login / Signup UI with form validation
- Mobile-friendly navigation with overlay menu
- Smooth animations and modern UI

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)

## 📂 Project Structure
```
├── index.html          # Landing page
├── movie-details.html  # Movie details page
├── login.html           # Auth page
├── style.css            # Main stylesheet
├── login.css            # Auth page styles
├── script.js             # Main site interactions
├── login.js              # Auth form logic
└── assets (images, icons, backgrounds)
```

## 💻 Getting Started

Clone the repo:
```bash
git clone https://github.com/harshtrivedi4480-cyber/Filmlane-Movie-website.git
cd Filmlane-Movie-website
```

Just open `index.html` in your browser — no build step required. For a local dev server:
```bash
npx serve .
```

## ▲ Deploy on Vercel
1. Push this project to a GitHub repository
2. Go to [vercel.com](https://vercel.com) → **New Project** → Import your GitHub repo
3. Framework preset: **Other** (static site) — no build command needed
4. Click **Deploy**
